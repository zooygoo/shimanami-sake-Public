# SHIMANAMIの酒 運営引き継ぎガイド

## サイトと管理画面を開く

| 用途 | 現在のリンク |
| --- | --- |
| 公開サイト | [SHIMANAMIの酒](https://zooygoo.github.io/shimanami-sake-Public/) |
| 管理画面 | [管理画面](https://zooygoo.github.io/shimanami-sake-Public/admin/) |
| 利用統計の記録表 | [Google スプレッドシート](https://docs.google.com/spreadsheets/d/10MoKMuc7oLoBlgyvnn-LEu_eyX1NfMH2erNEOwSi8IE/edit#gid=90010001) |

会社への移管後の公開サイト・管理画面のURLと、記録表のURL・閲覧権限は要確認です。引き継ぎ時に案内されたリンクをブックマークしてください。

1. 上の管理画面のリンクを開きます。公開サイトの一番下にある「管理」からも開けます。
2. 「管理者ログイン」の「パスワード」に、引き継いだ管理者用パスワードを入力し、「ログイン」を押します。
3. 日常の登録や編集には、公開サイト内の「管理画面」を使ってください。Googleから直接開く管理画面は旧画面で、所有者が管理者用パスワードを初期設定するときに使います。
4. 作業が終わったら「ログアウト」を押します。

## 造り手・体験・イベントを更新する

| メニュー | 登録・修正 | サイトから取り下げるとき |
| --- | --- | --- |
| 「造り手」 | 「編集する項目」で登録済みの事業者を選び、「事業者名」「一覧の紹介文」などを修正します。 | 事業者の追加と削除はこの画面ではできません。必要になったらサイトの管理担当者へ連絡してください。 |
| 「体験」 | 登録は「新しく追加」を押し、「種類」「タイトル」「紹介文」などを入力します。修正は「編集する項目」から選びます。案内を掲載するときは「画面に表示する」にチェックを入れます。予約ボタンも載せる場合は「予約URL」を入力し、「予約サイトを表示する」にチェックを入れます。 | 「編集する項目」で対象を選び、「画面に表示する」のチェックを外して保存します。 |
| 「イベント」 | 登録は「新しく追加」を押し、「タイトル」「内容」「開始日」などを入力します。複数日の場合は「終了日（複数日にわたる場合）」も入力します。修正は「編集する項目」から選びます。案内を掲載するときは「サイトに公開する」にチェックを入れます。 | 「編集する項目」で対象を選び、「サイトに公開する」のチェックを外して保存します。 |

1. 入力したら「変更内容を確認」を押します。「変更内容の確認」で内容と公開状態を確かめ、「この内容で保存する」を押します。
2. 「保存しました。サイトを開き直すと反映されます。」と出たら、「サイトで変更を確認」で該当箇所を開きます。掲載する内容は表示されていること、取り下げた内容は見えなくなったことを確かめます。

体験とイベントを取り下げても、入力した内容は管理画面に残り、再公開できます。この画面から項目そのものを削除する機能はありません。

## 写真を登録・交換・削除する

「編集する項目」で対象を選び、次のボタンを使います。選べるファイルは JPEG・PNG・WebP で、1枚10MB以下です。酒類の商品写真は登録しないでください。

| 対象 | 登録 | 交換 | 削除 |
| --- | --- | --- | --- |
| 「造り手」の「事業所の写真」 | 「写真を追加」 | 対象の写真の「画像を変更」 | 対象の写真の「削除」 |
| 「造り手」の「ロゴ」 | 「画像を選ぶ」 | 「画像を変更」 | 「削除」 |
| 「体験」・「イベント」の「写真」 | 「写真を選ぶ」 | もう一度「写真を選ぶ」 | 「削除」 |

1. 登録・交換ではファイルを選び、プレビューを確認します。「事業所の写真」は6枚までで、1枚目が代表写真です。「前へ」「後へ」で順番を変えられます。
2. 「変更内容を確認」を押し、「この内容で保存する」を押します。選択した写真はこのとき送信されます。
3. 管理画面で同じ項目を開き直し、写真が保存されたか確かめます。公開中の項目は「サイトで変更を確認」でも写真の表示や取り下げを確認します。

管理画面から登録した写真は、運営用 Google スプレッドシートの非表示タブ「写真データ」に保存されます。「削除」を保存すると項目から写真の表示が外れます。写真のデータはシートに残るため、写真が増えるとシートが重くなることがあります。

## 利用統計の記録表を見る

1. 上の記録表を閲覧権限のある Google アカウントで開き、「アクセス解析」タブを見ます。開けないときは、運営用シートの所有者に閲覧権限を確認してください。
2. 見たい日付と時間帯を指定します。全日を見るときは日本時間の 00:00〜24:00 を選びます。集計は日付の両端と開始時刻を含み、終了時刻を含みません。
3. 「サイト閲覧数」はトップと造り手詳細が開かれた回数、「造り手ページ閲覧数」は造り手詳細だけの回数です。「体験リンククリック数」「イベントリンククリック数」は、それぞれ体験・イベントの案内先リンクが押された回数です。「未計測」はクリックの記録が始まる前の状態を示します。日別・時間帯別の集計や項目別の内訳も見られます。
4. 管理画面でも「閲覧数」を開き、「開始日」「終了日」「開始時刻（毎日）」「終了時刻（毎日）」を指定して「表示する」を押すと確認できます。

## 困ったとき

| 症状 | 確認する順番 |
| --- | --- |
| 保存した内容がサイトに出ない | 保存完了の表示を確認し、「サイトで変更を確認」から公開ページを開き直します。「体験」の「画面に表示する」や「イベント」の「サイトに公開する」が選ばれているか確認します。「最新情報を取得できませんでした。再読み込みしてください。」が出たら、公開ページを再読み込みします。同じ状態が続いたら、項目名と表示された案内を管理担当者に伝えます。 |
| 管理画面にログインできない | 上にあるサイト内の管理画面を開き、管理者用パスワードを確認します。「しばらく待ってからログインしてください。」が出たら、時間をおいて再試行します。「接続を再確認」が出たら押します。「所有者による管理者パスワードの初期設定が必要です。」が出たら、運営用 Google アカウントの所有者に初期設定を依頼します。 |
| 写真が表示されない | 対象の項目を開き、写真のプレビューと保存完了の表示を確認します。体験・イベントでは公開のチェックも確認します。保存中にエラーが出たら、入力を残したまま案内を確認し、写真を選び直すか保存を再試行します。保存済みの写真が読み込めない場合は「再読み込み」で確認し、続く場合は項目名と案内を管理担当者に伝えます。 |
